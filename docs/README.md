# mtlsim Documentation

This directory contains the documentation for the mtlsim project. The documentation is organized into several sections, covering the project from usage to implementation details.

1. [Installation](installation.md): Instructions on how to install mtlsim on your system.
2. [Usage](usage.md): A guide on how to use mtlsim, including command-line options and configuration settings.
    1. [Data Ingestion](usage.md#data-ingestion): Details on how to ingest data into the simulator.
    2. [Simulation](usage.md#simulation): Instructions on how to run simulations using mtlsim.
    3. [Analysis](usage.md#analysis): Guidance on how to analyze the results of simulations.
3. [Architecture](architecture.md): An overview of the simulator's architecture, including its components and how they interact.
